# Installation guide

## Requirements

- Node.js 20 or later
- A current Chromium, Firefox, or Safari browser
- HTTPS for deployment (microphone permission is restricted to secure contexts)

## Local development

1. Run `npm install`.
2. Run `npm run dev`.
3. Open the URL printed by Vite and permit microphone access.
4. Wear headphones before starting a session.

Run `npm run lint`, `npm test`, and `npm run build` before committing.
